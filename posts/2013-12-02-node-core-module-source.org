#+TITLE: Node.js: how to get core module source
#+DATE: <2013-12-02>
#+TYPE: note
#+FILETAGS: :js:
#+DESCRIPTION: How to see the core node.js module source code.

It is possible to ask node to show its core module source.
For example, we want to check the source of the =readFileSync()= method:

#+begin_example
$ node
> fs = require('fs');
> fs.writeFileSync('fs.js', fs.toString())
> fs.writeFileSync('fs.readFileSync.js', fs.readFileSync.toString())
[Ctrl-C][Ctrl-C]
#+end_example

Now check the =fs.readFileSync.js= file in the current folder.

Also, on some systems, the source code of core node modules is in =/usr/lib/nodejs/=.

And another (less interesting) way to get the core module source is to look
for it in the node GitHub repository:
 * check the installed node.js version (=node --version=)
 * find the appropriate release on GitHub ([[https://github.com/nodejs/node-v0.x-archive/releases][releases]]), for example, [[https://github.com/nodejs/node-v0.x-archive/releases/tag/v0.8.17][0.8.17]]
 * click the commit id on the left: [[https://github.com/nodejs/node-v0.x-archive/commit/c50c33e9397d7a0a8717e8ce7530572907c054ad][c50c33e]]
 * click "Browse code" and see the [[https://github.com/nodejs/node-v0.x-archive/tree/c50c33e9397d7a0a8717e8ce7530572907c054ad][source]]
