* Code blocks
Emacs colors the code at build time (htmlize). Move the mouse over a block to see the copy button.

#+BEGIN_SRC python :results output :exports both
from pathlib import Path

for post in sorted(Path("posts").glob("*.org")):
    print(post.stem)
#+END_SRC

* Config preview (custom)

#+HTML_HEAD_EXTRA: <script defer src="/static/config-preview.js"></script>

The custom popup is implemented in a separate javascript file that can be included like this:

#+begin_example
    #+HTML_HEAD_EXTRA: <script defer src="/static/config-preview.js"></script>

    [[file:files/cwl-setup.config][cwl-setup.config, click to preview in popup]]
#+end_example

Here is a live example:
[[file:files/cwl-setup.config][cwl-setup.config, click to preview in popup]]

File can also be displayed in the HTML =<details>= tag:

#+begin_details
#+begin_summary
cwl-setup.config ([[file:files/cwl-setup.config][download]])
#+end_summary
#+include: "files/cwl-setup.config" src yaml
#+end_details

* HTML Export

The =#+begin_export html= and =#+end_export= allow inserting HTML snippets that
will be added to the HTML after org export:

#+begin_example
#+begin_export html
<div class="demo-popup">
    <div class="close">close</div>
    <div class="download"><a href="">Download (<span class="name"></span>)</a></div>
    <div class="popup-content"></div>
</div>

<style type="text/css">
  .demo-popup { display: none; }
</style>

<script type="text/javascript">
    document.addEventListener("DOMContentLoaded", () => {
        console.log("The DOM is fully parsed and ready!");

        // });
    });
</script>
#+end_export
#+end_example
