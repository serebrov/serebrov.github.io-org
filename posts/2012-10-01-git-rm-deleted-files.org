#+TITLE: git: remove deleted files from git
#+DATE: <2012-04-03>
#+TYPE: note
#+FILETAGS: :git:
#+DESCRIPTION: Git: how to remove already deleted files from git control.

We can use =git rm file-name= for one file, but we can also tell git to remove all
missing files.

To remove files that were already deleted on the file system but are still tracked by git,
run =git add= with the =-u= flag:

#+begin_src shell
git status
# D abc.c

git add -u
#+end_src

This tells git to automatically stage tracked files, including the deletion of
the previously tracked files.
