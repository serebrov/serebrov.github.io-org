#+DESCRIPTION: How to trigger a jQuery event on an element from Selenium WebDriver with executeScript.

The =executeScript= method of the webdriver receives additional =arguments= variable and we can pass WebElement instances to the script.
So triggering an event on the element can be done like this (python):

#+begin_src python
event = 'click' #or 'hover' or any other
script = "$(arguments[0]).trigger('"+event+"')"
webdriver.execute_script(script, web_element)
#+end_src
