#+TITLE: jQuery: global ajax response handler and jquery.localtime plugin
#+DATE: <2012-09-25>
#+TYPE: note
#+FILETAGS: :js:
#+DESCRIPTION: How to convert dates to local time in all ajax responses with a jQuery ajax prefilter and the jquery.localtime plugin.

The [[http://code.google.com/p/jquery-localtime][jquery.localtime plugin]] allows converting date/time strings to a local user time on a client side.
By default it works when the page is loaded initially, but if some elements are updated via ajax then they are not converted and are left in an UTC format.

A possible solution is to add some special handling to =$.ajax= =success= handlers, but it can require a lot of modifications.
A better way is to set some global handler for all ajax requests and apply conversion to local time there.
I evaluated several approaches before I could find a working solution.

* First try - run local time conversion in =$.ajaxComplete= (doesn't work)

#+begin_src js
$('body').ajaxComplete(function() {
    //code from jquery.localtime.js, jQuery.ready handler
    var format;
    var localise = function () {
        if (jQuery(this).is(":input")) {
            jQuery(this).val(jQuery.localtime.toLocalTime(jQuery(this).val(), format));
        } else {
            jQuery(this).text(jQuery.localtime.toLocalTime(jQuery(this).text(), format));
        }
    };
    var formats = jQuery.localtime.getFormat();
    var cssClass;
    for (cssClass in formats) {
        if (formats.hasOwnProperty(cssClass)) {
            format = formats[cssClass];
            //this will try to convert already converted texts and cause an exception
            jQuery("." + cssClass).each(localise);
        }
    }
});
#+end_src

It doesn't work because =jQuery("." + cssClass).each(localise)= will try to apply localization to all elements, including those which are already present in the page and converted.
And localtime plugin starts throwing exceptions because it can not convert already converted data.

* Second try - run local time conversion in =$.ajaxComplete= only for received data (doesn't work)

It doesn't work because =ajaxComplete= is invoked too late - when original =$.ajax= =success= handler has already done its work.

* Third try - use =$.ajaxSetup= converters (doesn't work)

#+begin_src js
$.ajaxSetup({
    converters: {
        "html html": function( textValue ) {
            return localizeText(textValue);
        }
    }
});
#+end_src

It doesn't work because converter is invoked only when we have two different formats like "text html" and we got unexpected format in ajax result.

* Final try - use =$.ajaxSetup= prefilters (works!)

#+begin_src js
jQuery(function($) {
    $.ajaxPrefilter(function(options, originalOptions, jqXHR) {
        var success = options.success;
        //if requested data type was text or html or *
        if (options.dataTypes.indexOf("text") !=-1 ||
            options.dataTypes.indexOf("html") != -1 ||
            options.dataTypes.indexOf("*") != -1
        ) {
            options.success = function(data, textStatus, jqXHR) {
                // override success handling
                data = localizeText(data);
                if(typeof(success) === "function") return success(data, textStatus, jqXHR);
            };
        }
    });

    function localizeText(textValue) {
        var format;
        var localise = function () {
            if (jQuery(this).is(":input")) {
                jQuery(this).val(jQuery.localtime.toLocalTime(jQuery(this).val(), format));
            } else {
                jQuery(this).text(jQuery.localtime.toLocalTime(jQuery(this).text(), format));
            }
        };
        var formats = jQuery.localtime.getFormat();
        var cssClass;
        //convert text to jQuery var
        var result = $(textValue);
        for (cssClass in formats) {
            if (formats.hasOwnProperty(cssClass)) {
                format = formats[cssClass];
                result.find("." + cssClass).each(localise);
            }
        }
        var text = "";
        //convert jQuery var back to text
        $(result).each(function(index){
            if (this.nodeName.toLowerCase() == 'script') {
                text += '<script type="text/javascript">'+$(this).html()+"</"+"script>";
            } else if (this.nodeType !== 1) {
                //skip non-elements (HTML comments, text, etc)
                return;
            } else {
                text += $(this).appendTo('<div>').parent().html();
            }
        });
        return text;
    }
});
#+end_src

This approach finally works.

The tricky part here is also a text-to-jQuery-and-back conversion.
While we can create a jQuery object (or array of objects) like this: =$(textValue)= and then process it, it is not so easy to convert it back to text.

After the conversion we have =result= as an array of jQuery objects and if we do =result.html()= then we get only inner HTML of the first item.

And even if we wrap the result into a parent div like this =$(result).appendTo('<div>').parent().html()= then we get HTML but without javascript elements.
So we need to iterate over the result and process HTML and javascript elements separately:

#+begin_src js
$(result).each(function(index){
    if (this.nodeName.toLowerCase() == 'script') {
        text += '<script type="text/javascript">'+$(this).html()+"</"+"script>";
    } else if (this.nodeType !== 1) {
        //skip non-elements (HTML comments, text, etc)
        return;
    } else {
        text += $(this).appendTo('<div>').parent().html();
    }
});
#+end_src
