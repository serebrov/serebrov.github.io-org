#+TITLE: git: use vim with fugitive to resolve merge conflicts
#+DATE: <2012-04-24>
#+TYPE: note
#+FILETAGS: :vim:git:
#+DESCRIPTION: Vim: how to use fugitive as a git merge tool

To use fugitive as a merge tool you can run the following commands:

#+begin_src shell
git config --global mergetool.fugitive.cmd 'vim -f -c "Gdiff" "$MERGED"'
git config --global merge.tool fugitive
#+end_src
