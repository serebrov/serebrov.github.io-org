#+TITLE: git: find all branches where file was changed
#+DATE: <2012-09-30>
#+TYPE: note
#+FILETAGS: :git:
#+DESCRIPTION: How to find all branches where a specific file was changed.

Find all branches which contain a change to FILENAME (even if before the
(non-recorded) branch point):

#+begin_src shell
git log --all --format=%H FILENAME | while read f; do git branch --contains $f; done | sort -u
#+end_src

Manually inspect:

#+begin_src shell
gitk --all --date-order -- FILENAME
#+end_src

Find all changes to FILENAME not merged to master:

#+begin_src shell
git for-each-ref --format="%(refname:short)" refs/heads | grep -v master | while read br; do git cherry master $br | while read x h; do if [ "`git log -n 1 --format=%H $h -- FILENAME`" = "$h" ]; then echo $br; fi; done; done | sort -u
#+end_src
