#+DESCRIPTION: How to enable colors for git output.

* Git me some colors!

To have a more colorful git output, use the following command:

#+begin_src shell
git config color.ui true
#+end_src

or (globally)

#+begin_src shell
git config --global color.ui true
#+end_src

Alternatively, you can set color for individual git commands.

#+begin_src shell
git config color.branch auto
git config color.diff auto
git config color.interactive auto
git config color.status auto
#+end_src

See also =color.*= options in the [[https://git-scm.com/docs/git-config][git config docs]].
