#+TITLE: Elastic Beanstalk: cron command and RDS DB access
#+DATE: <2013-10-22>
#+TYPE: note
#+FILETAGS: :aws:
#+DESCRIPTION: How to set up a cron command with RDS DB access on Elastic Beanstalk.

* Problem
:PROPERTIES:
:CUSTOM_ID: problem
:END:

We want to have a cron command that launches a PHP script with DB access.

The DB connection string looks like this:

#+begin_example
'connectionString' => 'mysql:host='.$_SERVER['RDS_HOSTNAME'].';port='.$_SERVER['RDS_PORT'].';dbname='.$_SERVER['RDS_DB_NAME'],
#+end_example

where the =RDS_xxx= parameters come from environment variables.

The problem is that cron launches the command with a clean environment
(there are no =RDS_xxx= variables). So the command fails to access the
database.

* Solution
:PROPERTIES:
:CUSTOM_ID: solution
:END:

The solution is to set the required environment variables before
launching the command, and this can be done with the
=/opt/elasticbeanstalk/support/envvars= script:

#+begin_example
  0 3 * * * . /opt/elasticbeanstalk/support/envvars; /var/www/html/console/yiic mycommand
#+end_example
