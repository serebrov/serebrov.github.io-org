#+TITLE: Vue CLI Service: Out of Memory Error during Build
#+DATE: <2024-04-05>
#+TYPE: note
#+FILETAGS: :vue:
#+DESCRIPTION: Solving the problem with Vue Cli build failing with out of memory error.

If you encounter an out-of-memory error during the frontend build, you
can increase the memory limit for the node process by setting the
=NODE_OPTIONS= environment variable:

#+begin_src shell
export NODE_OPTIONS=--max_old_space_size=8192
npm run build -- --mode production
#+end_src

Note that it should be enough to build the frontend application with the
default memory limit. Increasing the limit is a temporary measure to be
able to [[./2024-04-05-profile-vue-cli-service-build.html][profile and debug the build process]].
