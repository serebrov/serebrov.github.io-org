#+TITLE: git: keep 'git log' and 'git diff' output on the screen
#+DATE: <2014-01-04>
#+TYPE: note
#+FILETAGS: :git:
#+DESCRIPTION: How to keep 'git log' and 'git diff' output on the screen after exit

When =git= uses =less= as a pager, the output of commands like =git log=
disappears from the console screen when you exit from =less=.

This is not convenient in many cases, so here is how to fix this.

A fix just for git commands:

#+begin_src shell
git config --global --replace-all core.pager "less -iXFR"
#+end_src

For the =less= command, globally (including git), add the instruction below to your shell profile
(=.bashrc=, =.zshrc=, etc.):

#+begin_src shell
export LESS=-iXFR
#+end_src

Options we set for =less=:

- =-i= - ignore case when searching (but respect case if the search term
  contains uppercase letters)
- =-X= - do not clear the screen on exit
- =-F= - exit if the text is shorter than one screen
- =-R= - was on by default on my system, something related to colors
