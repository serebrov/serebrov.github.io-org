Vue.js CLI: multiple vue.config.js configs

It can be useful to have more than one configuration file, for example, to build several code bundles.

The config file to use can be set with the VUE_CLI_SERVICE_CONFIG_PATH environment variable: 

# Build using vue.config.public.js
CONF=`realpath vue.config.public.js`
VUE_CLI_SERVICE_CONFIG_PATH=$CONF npm run build -- --mode production

# Build using vue.config.js
npm run build -- --mode production

Where npm run build is defined in package.json as vue-cli-service build.

It is also possible to create several bundles using Vue CLI multi-page mode, but in this case we will have a big common JS and CSS "vendors" package.

The JS bundle problem is solvable with custom chunk settings, but it still leaves a big shared CSS package (I didn't find a solution for that).

The separate vue.config.js file has the advantage of building a completely independent bundle.

The alternative (check the comments) is to have separate configs and copy them over, but this is less convenient than using the environment variable.

Note: I didn't find any mention of VUE_CLI_SERVICE_CONFIG_PATH in the documentation. I found it by looking at the source code.
