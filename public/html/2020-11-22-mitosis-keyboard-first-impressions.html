Mitosis Keyboard First Impressions

I received my Mitosis a few days ago, and I like it a lot so far:

  • The size: perfect for the 36-key layout I use
  • The shape: very comfortable, lowered outer columns feel great for pinkies
  • I wish the inner column for the index finger were not shifted up as it is: it causes a bit of extension to use Y and T (not a big deal though)
  • I also think the bottom thumb row is too far, so I am using the top row, with the bottom one left without keycaps, so it doesn't get in the way
  • Wireless: this was probably one of the main reasons to get it. It is really nice to freely move both halves without having to care about wires
  • An interesting decision here is to use the radio channel instead of Bluetooth, which gives a much longer battery life
  • It requires a receiver to be connected to the computer, but that is not a big deal. Also, it is cool to realize that your keyboard (QMK) is actually running inside that small board
  • Layout: I am not sure which layout was there initially. It was QWERTY, while the default layout in the QMK configurator is Maltron (I think). Anyway, I changed it to my layout, similar to what I have on my Moonlander
  • Open source: here is the announcement post, hardware, receiver firmware and keyboard firmware, QMK

Getting it to work didn't take much time, although I first had an issue with the cable (the first one I tried didn't work; it was probably just not a data cable), and then I had the batteries upside down and one of them didn't stay in place.

I wish there were a quick start guide, something like this:

  • Unscrew the PCBs from the case (inner screws)
  • Put the batteries into the left and right halves. They go between the top and bottom plates, in the bottom right corner of the right half and the bottom left corner of the left half
  • Note that the battery position is different in the left and right halves
  • Don't screw the PCBs back yet. First, make sure it works
  • Find a micro-USB to USB-A/USB-C cable. It should be a data cable (so some cables may not work)
  • Connect the receiver to a computer
  • Try pressing keys on both halves. It should already work
  • Screw the PCBs back into the case
  • Put on the keycaps (it ships without keycaps)

If it doesn't work:

  • Make sure to use a data cable for the receiver
  • Make sure the batteries are inserted with the correct polarity
  • There are + and - markings, although I had to put my batteries upside down (+ battery side facing - marking). I am not sure if the markings are misplaced or I am interpreting them incorrectly

Flashing:

  • Go to the QMK configurator, change the layout as you like
  • Download the JSON keymap (at least as a backup, so it can be loaded back later)
  • Compile and download the firmware (there are buttons in the configurator) and then flash it with the QMK Toolbox
  • Press the button with R near it on the receiver to reset it and enter the flashing mode

Alternatively, clone QMK and flash from the command line. The setup guide is here. After everything is set up, new firmware can be compiled and flashed with qmk flash -kb mitosis -km mitosis_mini (where mitosis_mini is the custom keymap name, and there are also several alternative keymaps in the QMK source).

The keymap itself can remain in JSON format. Here is what I have so far:

  • config.h - defines the auto shift timeout and enables tapping force hold
  • custom.c - LED colors for layers (although I have a problem with the green light)
  • keymap.json - the keymap made with the QMK configurator
  • rules.mk - enables auto shift

Compared to the ZSA configurator, the QMK configurator provides fewer features, so I had to switch to the source code to enable auto shift.

I still have a few questions. Maybe someone could answer them for me:

  1. The battery didn't stay in place in the right half, so I put aluminum foil under it to keep it in place. It seems to work well now, but is it safe to keep it like this in the long term? Maybe there is a better way to fix this? Here is how the battery with foil looks.
  2. There are + / - markers on the PCB, but I had to put the batteries upside down to make it work (so the battery's plus is facing the plate marked with minus). It is the same on both sides. Am I interpreting these markings wrong? (It works, so it is not very important; I am just curious.)
  3. The green light doesn't seem to work in the indicator LED. Is this a defective LED or a soldering defect? How can I "debug" it? The blue and red lights work separately and together, producing magenta, but the green doesn't work on its own or when combined with red or blue; it just stays off.
  4. What do I do with several boards that I like a lot? I now have an ErgoDox EZ, a Moonlander and a Mitosis. Should I cycle between them daily or weekly?
