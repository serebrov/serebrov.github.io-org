A collection of links to touch typing tutors and games.

Online Typing Tutors

  • keybr.com - Typing practice, supports QWERTY, Dvorak, Colemak and Workman layouts
  • typing.com - Typing practice, free
  • typing.io - Typing Practice for Programmers
  • monkeytype.com - a minimalistic, customizable typing test, featuring many test modes, open source
  • entertrained.app - practice by typing books
  • typ.ing - typing trainer by zsa.io
  • TypingGym - typing trainer with automatic level increase, article mode (long text), code mode
  • Programmer's typing practice - no timers, no WPMs - just a never-ending stream of gibberish, open source
  • speedtyper.dev - Typing competitions for programmers, code snippets from open source projects in different languages, open source
  • typelit.io - practice typing by retyping entire novels
  • codingspeedtest.com - coding speed test, different languages (including assembly and machine code)
  • typingmentor.com - typing practice, live per-word WPM measurements
  • keyhero.com - Typing test and lessons
  • learntyping.org - typing lessons with detailed explanations
  • Typing Bee - typing lessons and games
  • The Typing Cat - Free online keyboard typing tutor
  • TypingClub - Learn Touch Typing Free
  • Ratatype - Online typing tutor and typing lessons
  • Typing Scout - Faster typing means more spare time :)
  • 10FastFingers.com - Typing Test, Competitions, Practice & Typing Games
  • TyperA - the original typing test
  • Typing Academy - typing test and practice
  • TypingStudy - Touch Typing Practice Online
  • Ngram Type - Practice typing bigrams, trigrams, tetragrams and top words
  • speedcoder.net - Online Typing Practice for Programmers

Keyboard Memo

Keyboard with finger positions:

Shows which key should be pressed with which finger (middle pink is for index fingers, green for middle fingers and so on).

Grey keys: I usually use the pinky here (except for the space bar).

Space bar: Press with the left thumb after typing a letter with the right hand and with the right thumb after typing a letter with the left hand.
